# What We Ship TODAY - builder.faf.one

## The Product
**1-Click GitHub OAuth to initialize project.faf in any repo**

## What Works
✅ Serverless-friendly template generation (no exec, no temp files)
✅ GitHub OAuth flow (authorize → generate → commit)
✅ README extraction (WHO/WHAT/WHY/WHERE/WHEN/HOW)
✅ Stack detection (React, Vue, Svelte, Express, Next.js, Node.js)
✅ Auto-scoring (typically 85%+ Bronze tier)
✅ Clean UX (one green button, auto-check on modal open)
✅ Success screen with optional improvement form

## The Flow
1. User enters GitHub URL (e.g., `https://github.com/Wolfe-Jam/test-faf-demo`)
2. Modal auto-checks if project.faf exists
3. If missing: Green button "Initialize project.faf →"
4. Click → GitHub OAuth authorization
5. Return → Auto-generate + commit project.faf
6. Show score (typically 85%+) with optional improvement

## Tech Stack
- **Framework**: SvelteKit 5
- **Deployment**: Vercel (serverless)
- **Generation**: Template-based (no CLI dependencies)
- **OAuth**: GitHub OAuth App (Device Flow enabled)

## What It Generates
```yaml
# project.faf - AI Context Format
# Generated by builder.faf.one
# Learn more: https://faf.one

project:
  name: repo-name
  version: 0.0.0
  created: 2026-02-04T...

repository:
  owner: username
  repo: repo-name
  url: https://github.com/username/repo-name

context:
  who: username team
  what: [extracted from README title or repo description]
  why: [extracted from README purpose/mission]
  where: GitHub
  when: Initialized 2026-02-04
  how: [detected from README installation section]

stack:
  primary: React/Vue/Svelte/etc
  dependencies: react, react-dom, ...

ai_readiness:
  score: auto
  initialized_by: builder.faf.one
  readme_extracted: true
```
